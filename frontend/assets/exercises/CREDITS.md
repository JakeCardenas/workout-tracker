# Exercise illustrations

The 192 SVG frames in this folder (64 exercises, three frames each) are not my
work. They come from the Workout Guide asset library by **Bryl Lim**:

- Source: https://github.com/bryllim/workout-guide
- Site: https://bryllim.github.io/workout-guide/
- Licence: **CC BY-SA 4.0** — https://creativecommons.org/licenses/by-sa/4.0/

## Changes made

Two edits, applied to every file:

1. `fill="#fff"` replaced with `fill="currentColor"`, so the figures inherit the
   page's text colour and work on a light background. The originals are drawn
   white for dark backgrounds.
2. The fixed `width="512" height="512"` attributes removed, leaving `viewBox`,
   so CSS controls the size.

The path data is untouched.
